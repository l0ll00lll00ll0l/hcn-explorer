# HCN Algorithm Documentation

## Overview

This project implements an algorithm for finding **Highly Composite Numbers (HCNs)** — positive integers that have more divisors than any smaller positive integer. Examples: 1, 2, 4, 6, 12, 24, 36, 48, 60, 120...

The algorithm uses a matrix-based approach with prime factorization, proving HCNs in order by extending a "last active prime index" and comparing candidates by their divisor counts (factors).
